# 📨 로컬 알림톡 발송기(beta)

매월 엑셀로 정리한 발송정보를 카카오 알림톡으로 손쉽게 예약 발송하는 로컬 실행형 도구입니다.

- ✅ 개인정보는 **내 PC 안에서만** 처리 — 외부 서버 전송 없음
- ✅ 엑셀 업로드 → 변수 매핑 → 알림톡 예약 발송까지 **3단계**로 완료
- ✅ 발신 프로필(채널)별 **서비스 분리** 관리
- ✅ **실시간 알림톡 미리보기** 위젯으로 발송 전 내용 확인
- ✅ 발송 상태 자동 폴링 및 **이력 관리**

---

## 🚀 시작하기

### 1. 사전 준비

| 항목 | 설명 |
|------|------|
| **Python 3.11+** | [python.org](https://python.org) 에서 설치 |
| **Solapi 계정** | [solapi.com](https://solapi.com) 회원가입 후 API 키 발급 |
| **카카오 알림톡 채널** | Solapi에 카카오 비즈니스 채널(발신 프로필) 등록 및 알림톡 템플릿 **검수 완료** 필요 |

### 2. 설치 및 실행

```bash
# 의존성 설치
pip install -r requirements.txt

# 프로그램 실행
python main.py
```

실행 후 브라우저에서 자동으로 `http://127.0.0.1:5050` 이 열립니다.

---

## ⚙️ 최초 설정

상단바의 **[⚙ 설정]** 메뉴에서 Solapi API 인증 정보를 입력합니다.

| 항목 | 설명 |
|------|------|
| **API Key** | Solapi 콘솔 → 개발자 → API 키 관리에서 발급 |
| **API Secret** | API Key와 함께 발급됨 |

> 입력한 인증 정보는 로컬 PC의 데이터베이스에 암호화 저장되며, 외부에 전송되지 않습니다.

---

## 📋 사용 방법

### 1단계 — 서비스 생성

> **서비스**란 하나의 카카오 채널과 알림톡 템플릿을 묶어 관리하는 단위입니다.
> 예: "A빌딩 관리비", "B오피스텔 임대료" 처럼 분리하여 운영할 수 있습니다.

1. 메인 화면 상단바에서 **[+ 새 서비스]** 클릭
2. 서비스 이름, 발송 주기 선택
3. **발신 프로필(카카오 채널)** 선택
4. **알림톡 템플릿** 선택 (검수 완료된 템플릿만 정상 발송 가능)
5. **엑셀 헤더 설정** — 업로드할 엑셀 파일의 열 이름 등록
6. **변수 매핑** — 알림톡 템플릿의 `#{변수명}`과 엑셀 열을 연결
7. **[저장]** 클릭

### 2단계 — 청구 내역 입력

1. 메인 화면에서 서비스를 선택
2. 청구 기준 주기(월, 분기 등)를 화살표로 선택
3. **엑셀 파일 업로드** 또는 **엑셀에서 복사 → 붙여넣기**
4. 발송 대상자 정보 테이블에서 내용 확인 (셀 클릭 시 직접 수정 가능)

### 3단계 — 예약 발송 등록

1. 발송 대상자 정보 테이블에서 내용을 최종 확인
2. 우하단 📱 **알림톡 미리보기 위젯**으로 실제 발송될 내용 미리보기
3. **[예약 발송 등록]** 클릭
4. 발송 예정일·시간 확인 후 등록

> 발송 예정일은 `발송일` 열의 수식(예: `{납부기한} - 5일`)으로 자동 계산됩니다.

### 4단계 — 발송 상태 확인

- 메인 화면 상단 **발송 상태** 카드에서 완료/대기/실패 건수와 상세 이력 확인
- 5분마다 자동으로 갱신되며, **[↻ 새로고침]** 버튼으로 즉시 갱신 가능
- 페이지당 10 / 20 / 50 / 100건씩 나눠서 조회 가능

## 📁 설정 가져오기 / 내보내기

서비스 수정 페이지 하단에서 **설정 파일(JSON)** 을 내보내거나 가져올 수 있습니다.

- **내보내기**: 현재 서비스 설정(헤더, 매핑, 채널 정보)을 JSON 파일로 저장 → 백업 또는 다른 PC 이전용
- **가져오기**: 이전에 내보낸 JSON 파일을 불러와 서비스 설정 복원

## 🔒 개인정보 보호

|------|-----------|
| 세입자 연락처·이름 등 개인정보 | 내 PC 로컬 SQLite DB (`billingtalk.db`) |

| 알림톡 발송 내용 | Solapi 서버 (발송 처리 후 이력만 로컬 보관) |
